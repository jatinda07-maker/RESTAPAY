# RC6.19 Approved Payroll Payment Popup

- Edit Selected now opens a centered dashboard-style payment workspace.
- Shows all selected employees in a scrollable list with totals.
- Supports payment status, method, paid date, notes, and starting check number.
- Starting check numbers increment automatically for each selected employee.
- Approved Payroll table now uses horizontal scrolling and a safe minimum width so right-side columns and actions are not clipped.
- Toolbar wraps cleanly on smaller screens.
