# RESTAPAY RC3.9.34 - Restaurant Health Card

Adds a live Restaurant Health card to the Dashboard using the selected date range.

Score inputs:
- Operating margin
- Prime cost percentage
- Labor mix percentage
- Cash position
- Financial reconciliation status/variance

The card provides a 0-100 score, Excellent/Good/Watch/Needs Attention status, and five supporting measures. It uses existing live financial metrics only and does not modify Supabase data.
