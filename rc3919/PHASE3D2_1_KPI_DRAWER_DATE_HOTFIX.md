# Phase 3D.2.1 KPI Drawer Date Hotfix

- KPI/detail drawers now visibly expose the shared date preset, From, To, and Apply controls.
- Every drawer initializes from the currently applied global/page date range when opened.
- Drawer Apply changes only the drawer's scoped data and totals.
- Food Invoices and Alcohol Invoices now have real selected-period summaries instead of the generic zero-value fallback.
- No layout JSX or global styling files were changed.
