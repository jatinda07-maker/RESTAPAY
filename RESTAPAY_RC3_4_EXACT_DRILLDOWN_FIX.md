# RESTAPAY RC3.4 Exact KPI Drill-Down Fix

- KPI/detail lines now resolve to the exact live records that make up the displayed metric.
- Cash Expenses filters only cash operating expenses.
- Check & ACH filters only check/ACH expenses.
- Credit Expenses filters only card/credit expenses.
- Cash Vendor Invoices filters only cash-paid invoices.
- Payroll, food/alcohol invoice, sales, vendor, and employee detail mappings use their corresponding live collections.
- Clicking an Overview or By Category line opens the matching entries inside the same expanded detail panel.
- Explicit row detail passed by Expenses/Invoices/Price Increase/Vendor Comparison is honored.
- Entries are no longer limited to the first eight rows; the full matching set is shown for the selected drawer date range.
