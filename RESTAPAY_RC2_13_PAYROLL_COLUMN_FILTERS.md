# RESTAPAY RC2.13 - Payroll Column Filters

- Adds compact per-column filters to payroll/history tables for Date, Employee, Job, Hours, Base Pay, Tips, Withheld, Net Tips, Final Pay, Method, and Status.
- Defaults payroll rows to Date ascending, then Employee A-Z for rows on the same date.
- Keeps global search/method filtering and pagination working on top of the column filters.
- Adds a Clear Column Filters action when any column filter is active.
