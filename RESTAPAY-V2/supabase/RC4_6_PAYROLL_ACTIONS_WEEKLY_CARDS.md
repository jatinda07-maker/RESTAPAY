# RC4.6 Payroll Actions, Weekly Range, Cards and Button Colors

- Fixed Create Selected Payroll flow and removed check-number blocking during creation.
- Fixed Approve Pending to approve all visible pending rows in the selected date range.
- Default payroll range is Last Week.
- Added default weekly merge: one payroll row per employee for the selected range, ending on the selected end date.
- Date range remains editable and weekly merge can be turned off for daily payroll rows.
- Added four compact colored summary cards to Approved Payroll.
- Changed global primary action buttons from green to professional blue; success/approval actions remain green.
