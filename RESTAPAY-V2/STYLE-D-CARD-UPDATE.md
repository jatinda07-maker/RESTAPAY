# Style D Card Update

This package applies the compact Style D card system requested on 2026-07-30.

Updated:
- Dashboard white KPI cards
- Dashboard colored metric cards
- Expense KPI cards
- Shared card borders, radius, and shadows
- Slimmer sidebar sizing
- More transparent scrollbars

No calculation, Toast, payroll, Supabase, invoice, or vendor logic was intentionally changed.

Local verification:

```powershell
npm install --registry=https://registry.npmjs.org
npm run build
npm run dev
```
