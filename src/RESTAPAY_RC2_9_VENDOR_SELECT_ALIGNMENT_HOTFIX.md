# RESTAPAY RC2.9 Vendor Select Alignment Hotfix

Fixes the Add Vendor modal selector layout so Vendor Type, Category, and Expense Type show the selected text correctly while keeping the leading icon and add-new button aligned.

- Prevents RC2.6 generic form selector CSS from collapsing the Add Vendor controls.
- Keeps Expense modal two-column selector rows unchanged.
- Preserves RC2.8 vendor cleanup, merge/override, A-Z sorting, and date picker behavior.
