# RESTAPAY RC3.9.25 - Manager Dashboard Access

Adds Admin-configurable Manager Dashboard permissions to Users & Security > Manager > Edit.

- Individual ON/OFF controls for KPI cards and dashboard sections.
- Hidden Manager cards are removed entirely from the dashboard.
- Operating Profit, Prime Cost, and Weekly Profit default OFF for Manager.
- Dashboard route defaults ON so Manager can use the permitted dashboard.
- Select All, Clear All, and Restore Defaults controls included.
- Existing Navigation Access and Report Access settings preserved.
